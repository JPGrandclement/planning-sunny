# ⚡ Démarrage Rapide - Assistant Scolaire PWA

Guide ultra-rapide pour mettre en ligne l'application en 5 minutes.

## 🎯 Objectif

Rendre l'Assistant Scolaire accessible depuis le téléphone de votre fils via une URL simple.

## 📋 Ce dont vous avez besoin

- ✅ Un compte GitHub (gratuit)
- ✅ Les fichiers sont déjà prêts dans ce dossier

## 🚀 3 étapes simples

### Étape 1 : Créer un dépôt GitHub (2 min)

1. Allez sur https://github.com/new
2. Nom du dépôt : `assistant-scolaire`
3. Cochez "Public"
4. Cliquez sur "Create repository"

### Étape 2 : Uploader les fichiers (2 min)

**Dans votre nouveau dépôt GitHub :**

1. Cliquez sur "uploading an existing file"
2. Glissez-déposez ces fichiers :
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - Le dossier `icons/` (avec les 2 fichiers PNG)
3. Cliquez sur "Commit changes"

### Étape 3 : Activer GitHub Pages (1 min)

1. Dans votre dépôt, cliquez sur "Settings" ⚙️
2. Menu de gauche : "Pages"
3. Source : Sélectionnez "main" et "/ (root)"
4. Cliquez sur "Save"
5. **Attendez 1-2 minutes** ⏱️

## ✅ C'est prêt !

Votre application est maintenant en ligne à l'adresse :

```
https://VOTRE-USERNAME.github.io/assistant-scolaire/
```

Remplacez `VOTRE-USERNAME` par votre nom d'utilisateur GitHub.

## 📱 Installer sur le téléphone

**Envoyez l'URL à votre fils par SMS/WhatsApp**

### Sur Android :
1. Ouvrir l'URL dans Chrome
2. Appuyer sur "Ajouter à l'écran d'accueil"
3. ✅ L'icône apparaît !

### Sur iPhone :
1. Ouvrir l'URL dans Safari
2. Appuyer sur Partager (□↑)
3. "Sur l'écran d'accueil"
4. ✅ L'icône apparaît !

## 🎉 Terminé !

Votre fils peut maintenant :
- Lancer l'app depuis son écran d'accueil
- Consulter ses horaires de bus
- Voir son emploi du temps
- Utiliser l'app même sans connexion

## 🔄 Pour modifier les horaires plus tard

1. Allez sur votre dépôt GitHub
2. Cliquez sur `index.html`
3. Cliquez sur l'icône crayon ✏️
4. Modifiez les données
5. "Commit changes"
6. ✅ Mis à jour automatiquement !
